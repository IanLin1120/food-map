日日帳本 v3.29.0

・記帳頁的「常用紀錄」只顯示有幾個常用，不列名稱
・「購物紀錄」「購物明細」全部改名為「消費紀錄」「消費明細」
・只有吃喝的店才有菜單：停車場、加油站、超市、量販店這類店家，店家頁和地圖卡片不再顯示菜單，只有消費紀錄；分類可以自己勾「這類店家有菜單」
・店家頁的按鈕排列對稱（4 個排成 2×2）
・新增「同一個人，不同綽號」：例如日常點餐叫「便當哥」、記帳叫「因因」，設定後從分帳匯入記帳會自動對到同一個人；記帳名單裡兩個名字是同一人時，紀錄、欠款會併在一起。在記帳設定和日常設定都可以設定
・備份確認包含全部資料：收藏店家與菜單、點餐、分帳、發票、記帳（常用紀錄、帳戶、對帳、商家）、資產、購物清單、食譜、分類、所有設定和圖片，並新增備份 API 金鑰；手機、雲端、QR Code 換機都一樣。用 QR 傳給別人時可以選擇不帶金鑰
・使用說明全面改版：新增自動定位與選鄉鎮、關鍵字搜尋收藏、菜單只限吃喝的店、點餐選項、同一個人、上鎖與防止誤刪、完整備份內容等說明
